# 🖼️ Просмотрщик изображений - Лабораторная работа №3

## 📋 Описание проекта

Приложение для просмотра изображений с использованием паттерна **Iterator**, поддержкой фильтрации, анимацией переходов и чтением EXIF-данных.

## ✨ Функциональность

### Основные возможности
- ✅ Навигация по изображениям (вперед/назад/первое/последнее)
- ✅ Циклический переход (после последнего → первое, перед первым → последнее)
- ✅ Фильтрация по типу файлов (JPG, PNG, GIF, BMP, WEBP)
- ✅ Автоматический просмотр с регулируемой скоростью (0.5-5 сек)
- ✅ Три эффекта анимации переходов
- ✅ Отображение информации о файле (имя, размер, путь)
- ✅ Чтение EXIF-данных (камера, дата, параметры съемки)

### 🎬 Анимации переходов
| Эффект | Описание |
|--------|----------|
| Исчезание | Плавное затухание и появление изображения |
| Сдвиг | Горизонтальный сдвиг (влево/вправо) |
| Масштабирование | Эффект увеличения/уменьшения |

### 🎯 Фильтрация изображений
- Все форматы
- .jpg / .jpeg
- .png
- .gif
- .bmp
- .webp
